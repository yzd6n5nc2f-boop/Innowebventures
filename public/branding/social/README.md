# Social sharing assets

All five JPEGs are 1200 x 630 pixels. `default-share.jpg` is the branded fallback;
the four November variants use existing campaign artwork without changing the
original on-page images. Assignments live in `src/content/socialMetadata.json`.

The default was created with the built-in image generation tool using the
existing `public/branding/logo/innoweb-logo.png` as a reference, then exported at
the exact requested sharing size. The campaign variants were laid out for the
same size while preserving the original artwork's aspect ratio.

## Default image prompt

Use case: ads-marketing. Create the default website social sharing card for
InnoWeb Ventures, exactly 1200 x 630 pixels, landscape 1.90476:1 aspect ratio.
The supplied image is the existing brand mark reference: a monochrome circular
human profile/circuit monogram; preserve its recognisable shape. Create an
elegant polished business AI technology card with a very dark navy background,
restrained cyan light traces, fine neural connections and a subtle softly
luminous three-dimensional neural form on the right. Use the reference monochrome
brand mark tastefully as a small emblem. Strong typography on the left with
generous safe margins, white headline spelled exactly 'InnoWeb Ventures' and a
smaller line spelled exactly 'Intelligent workflows. Human control.' Small footer
text exactly 'www.innowebventures.com'. Clean professional premium graphic,
understated and legible at thumbnail size. No other text, no fake dashboards, no
robots or people, no mockup borders. Keep all important text and emblem within
the central 80 percent. Export the complete finished card, opaque background.
